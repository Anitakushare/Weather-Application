# Weather Forecast Application 

A responsive web application to fetch and display weather forecasts for cities, as well as the current location. The app features animations, validation, and user-friendly interactions, built with HTML, Tailwind CSS, and JavaScript.

## Features 

- **Search Weather by City Name**: Users can enter a city name to get its current weather and a 5-day forecast.
- **Current Location Weather**: Fetch weather for the user's current location using geolocation.
- **Recently Searched Cities**: Dropdown to select from previously searched cities, stored using local storage.
- **5-Day Weather Forecast**: Displays temperature, wind speed, humidity, and weather icons for the next 5 days in a grid format.
- **Responsive Design**: Mobile-friendly layout with smooth animations and Tailwind CSS utility classes.
- **Input Validation**: Ensures valid city names and prevents empty or invalid searches.
- **Error Handling**: Gracefully handles API errors and displays appropriate messages.

## Technologies Used 

- **HTML5**: Semantic structure for web pages.
- **CSS3 with Tailwind CSS**: Styling and responsive design.
- **JavaScript (ES6)**: Logic for fetching weather data, animations, and DOM manipulation.
- **OpenWeather API**: For fetching weather data.
